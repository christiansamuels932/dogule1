# Dogule1

Dogule1 is the main application workspace for the Dogule1 product, including UI, API, and supporting tooling.

Project layout (high-level):

- Code and runtime folders live at the root (apps/, modules/, tools/, migration/).
- Documentation lives under attachments/docs/.
- Archived historical docs live under attachments/archive/.
- The historical status log is preserved at attachments/status/status_log.md.
- Data is under data/.
- Generated outputs and reports are under exports/.
- Backups are under backups/.

For legacy quick-start commands and historical station logs, see attachments/status/status_log.md.
