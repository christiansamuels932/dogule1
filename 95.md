# Station 95 — Trainer minimal login (Rapport-only)

## Goal

- Provide a minimal trainer login role limited to Rapport draft creation.
- Ensure trainers can only access Rapport creation entry points and their own drafts.

## Scope

- New trainer role or role variant with limited module access.
- Login options updated to include minimal trainer accounts.
- UI access limited to relevant views (Kunde/Hund detail for rapport creation, dashboard draft list hidden).
- API access limited to Rapporte draft create/list (own only).

## Out of scope

- Full module access for trainers.
- Changes to admin/developer permissions.
- Notifications.
