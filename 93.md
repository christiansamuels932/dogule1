# Station 93 — Dashboard birthdays + Outlook mailto flow

## Goal

- Show today’s birthdays (Kunden + Hunde) on the Dashboard and allow:
  - **Verwerfen** (dismiss for today)
  - **Geburtstagsemail** (open Outlook via `mailto:` and mark handled for today)
- Write an audit trail (Historie) on the **Kunde** for each action.

## Scope

- Dashboard card: **“Heutige Geburtstage”**
  - Kunden birthdays (Geburtsdatum)
  - Hunde birthdays (Wurfdatum / `geburtsdatum`)
- Actions per entry: **Verwerfen** + **Geburtstagsemail**
- “Once per day” behavior: after handling, an entry must not reappear for the same day.

## Out of scope

- Automatic sending, delivery tracking, HTML templates
- Deduplication / merge workflows (report-only is fine)
