# Station 97 — NAS Deployment

## Goal

- Prepare and deploy the NAS payload via `.NAS-Distro`.
- Verify API + UI remotely after deployment.

## Scope

- Build and populate `.NAS-Distro` with the required app + API files.
- Deploy to NAS root and ensure API starts with correct env + password file.
- Remote verification of login and core flows.

## Out of scope

- NAS hardware changes or upgrades.
- Data migrations beyond the documented import workflow.
- New features unrelated to deployment readiness.
